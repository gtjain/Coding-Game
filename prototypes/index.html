Learning path

Ages 4–6: tap, no reading needed

Big targets, pictures instead of words, a voice that reads the instructions (tap 🔊), and no hearts to lose. Every game here is one level.

A1

Bunny Hop

Sequencing

Tap arrows to plan the bunny's hops, then press Go. Tap a planned arrow to remove it.

Design notes
  • Arrows move in screen directions (up is up). Turning left/right relative to the bunny is too abstract under 6.
  • The block lights up as it runs so kids link each block to each hop.
  • Later levels: longer paths, a second carrot to collect, then "hop twice" blocks.
A2

Pattern Train

Patterns

Spot the pattern and pick the next train car. Three rounds, each one a little harder.

Design notes
  • Patterns are the seed of loops: "red, blue, again".
  • Round types: AB, AAB, ABC. Later: fill a gap in the middle, or build your own pattern.
A3

Seed Steps

Order of steps

Put the picture cards in order: what happens first, next, last. Tap a filled box to take a card back.

Design notes
  • An algorithm is a recipe. Everyday routines (brushing teeth, making a sandwich) make that concrete.
  • Only the wrong boxes turn red, so kids fix part of the answer instead of starting over.

Ages 7–9: real programming ideas

Short text is fine here. Hearts make mistakes count, and stars reward shorter programs, the way coders aim for neat code.

B1

Loop Maze

Loops

Get the frog to the lily pad. Add a Repeat block, then tap arrows to fill it (tap the loop's box to fill it, the main box to add after it). 3 blocks or fewer earns ⭐⭐⭐.

Design notes
  • The staircase takes 10 single arrows. A Repeat ×5 of → ↑ takes 3 blocks. The star rule makes the loop worth discovering.
  • Next steps: nested loops, then "repeat until at the goal".
B2

Bug Hunt

Debugging

The robot's program has one wrong block. Run it, watch where it goes wrong, then tap a block to turn it.

Design notes
  • Reading code is a separate skill from writing it. Debugging builds it.
  • The failing block flashes red so the kid can trace cause and effect.
  • Later: two bugs, a missing block, or an extra block.
B3

Sorting Machine

If / else

Pick the condition that makes the machine sort correctly, then run it. Two puzzles.

IFit is…
THEN⬅ left basket

⬅ Left

Right ➡

Design notes
  • The skill is choosing which property matters (shape or colour), the core of writing a condition.
  • Later: AND/OR ("blue and a star"), then ELSE IF with three baskets.
