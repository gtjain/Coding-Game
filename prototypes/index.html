Learning path

Ages 4–6: tap, no reading needed

Big targets, pictures instead of words, a voice that reads the instructions (tap 🔊), and no hearts to lose. Games marked New are options to compare.

Unit 1 · First steps

Tap arrows to plan the bunny's hops, then press Go. Tap a planned arrow to remove it.

Design notes
  • Arrows move in screen directions (up is up). Turning relative to the bunny is too abstract under 6.
  • The block lights up as it runs so kids link each block to each hop.

Press Watch to see the robot's dance, then tap the moves in the same order.

🤖❔
Design notes
  • A program is a list of steps run in order. Remembering and replaying a sequence is the same skill without any arrows.
  • Rounds grow from 3 to 4 moves. Later: a move that repeats ("clap clap clap") as a first look at loops.

Spot the pattern and pick the next train car. Three rounds.

Design notes
  • Patterns are the seed of loops: "red, blue, again".
  • Round types: AB, AAB, ABC.

Put the picture cards in order: first, next, last. Tap a filled box to take a card back.

Design notes
  • An algorithm is a recipe. Everyday routines make that concrete.
  • Only the wrong boxes turn red, so kids fix part of the answer.

Unit 2 · Little loops and rules

Only 3 cards fit. Pick an arrow, then press + to make that card hop more times. The dots show how many hops.

Design notes
  • A loop without the word: "this arrow, 3 times". Dots show the count for kids who can't read numbers yet.
  • The 3-card limit makes repeating necessary, the same trick the 7–9 Loop Maze uses with stars.

Teach the bear a rule for each kind of weather, then press Go and watch the bear follow your rules.

🌤️🐻
Design notes
  • The kid writes the rules, then the bear runs them. If a rule is wrong, the bear wears sunglasses in the rain, which kids find funny and remember.
  • Later: two conditions ("rainy AND cold").

Follow the arrows in your head, then tap the square where the bunny will stop. Three rounds.

Design notes
  • Predicting what code does before running it. Good for 5–6 year olds who have played Bunny Hop.
  • After the guess, the bunny runs the arrows so the kid can check their thinking.

Ages 7–9: real programming ideas

Short text is fine here. Hearts make mistakes count, and stars reward shorter programs.

Unit 1 · Code moves

Get the frog to the lily pad. Add a Repeat block and fill it with arrows (tap a box to choose where arrows go).

Design notes
  • 10 single arrows work, but Repeat 5 × (→ ↑) takes 3 blocks. The star rule makes the loop worth finding.

The robot's program has one wrong block. Run it, watch where it crashes, then tap a block to turn it.

Design notes
  • Reading code is a separate skill from writing it.
  • The failing block flashes red so the kid can trace cause and effect.

The machine counts from START to STOP, jumping each time. At every count it builds a tower that tall. Make the towers fill the dotted outlines.

count = –

EACH TIME build a tower as tall as the count
Design notes
  • This is a for loop (for count = 2 to 8 step 2) without the name. The counter changes on each pass and the body uses it.
  • Three skylines: count up by 1, count by 2s, count down. Later: the kid writes the "each time" step too (tower = count × 2).

The kangaroo must jump three rocks. Put the jump's arrows inside ⭐ My block once, then use ⭐ in the main program. 9 blocks or fewer earns ⭐⭐⭐.

⭐ My block is:
Design notes
  • A function is a named list of steps you can reuse. The jump (↑ → → ↓) is written once and called three times.
  • Repeat is left out on purpose so the only way to 3 stars is your own block.

The robot draws as it moves. Trace the dotted shape exactly. ⬆ moves one dot forward, ↻ and ↺ turn on the spot.

Design notes
  • Turning is relative to the robot, which is a step up from screen arrows and fits 7–9.
  • Square, then staircase. Both are shortest with a Repeat, so drawing reinforces loops.

Design notes
  • A variable is a named box whose value changes. Wording follows Scratch ("set jar to", "change jar by").
  • Round 2 mixes in a loop, round 3 has a trap: doubling before subtracting gives 20.

Run the adding recipe with the buttons, in the right order. A column can hold at most 9.

  1. Push the ones together
  2. 10 or more ones? Trade 10 ones for 1 ten
  3. Push the tens together
  4. Read the answer
Design notes
  • Column addition is an algorithm with a condition (step 2) inside it. The kid runs it by hand.
  • Wrong answers on offer are the common mistakes: forgetting the carry (52) and writing 12 ones (512).

A mirror number reads the same forwards and backwards, like 121. Round 1: find them all. Round 2: run the flip-and-add machine until it makes one.

Design notes
  • Checking a palindrome is an algorithm: compare first and last digit, move inwards.
  • Flip-and-add is a "repeat until" loop. The kid decides when to stop, so they run the loop condition themselves.
